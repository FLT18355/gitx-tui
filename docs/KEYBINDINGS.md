# 键位说明

## GitHub 工作台

| 按键 | 作用 |
| --- | --- |
| `1` `2` `3` `4` `5` `6` | 仓库 / 收藏 / 搜索 / 账号 / 通知 / 热门 |

| `j` `k` | 上下移动或滚动 |
| `[` `]` | 上一页 / 下一页 |
| `g` `G` | 第一页 / 最后一页 |
| `PgUp` `PgDn` | 列表翻页或滚动面板 |
| `Enter` | 打开仓库页、执行设置项、打开主页或 Actions run |
| `Esc` | 离开输入、关闭弹窗或返回列表 |
| `/` | 仓库/收藏/搜索/热门页筛选当前列表；仓库页发行版面板筛选发行版；其他页面聚焦搜索 |
| `s` | 全局仓库搜索 |
| `l` | 仓库/搜索/热门页按语言筛选 |
| `b` | 仓库页/提交页切换分支 |
| `C` | 打开当前仓库的提交页 |
| `F` | 仓库页全屏查看 README |
| `a` | 当前仓库的 Actions 工作流页 |
| `i` | 当前仓库的议题与合并请求页 |
| `n` | 议题页新建议题 |
| `L` | 仓库页查看语言占比统计 |
| `Y` | 打开 Fork 小窗口，把别人的仓库 Fork 到自己的账号 |
| `D` | 删除自己的仓库（需要确认） |
| `R` / `x` | Actions 页打开「运行工作流」 |
| `c` | 缓存管理 |
| `e` | 编辑自己的仓库 |
| `f` | 收藏或取消收藏 |
| `o` | 用浏览器打开当前仓库 |
| `y` | 复制克隆地址 |
| `r` | 刷新当前页 |

| `?` | 操作说明 |
| `q` | 退出 |

### 鼠标 / 手机点击

- 点击仓库卡片选择，双击打开仓库页。
- 点击卡片或仓库页标题里的仓库作者，进入作者主页；主页里看详细资料和全部公开仓库，点仓库可继续打开。
- 点击排序、语言、主题卡片、按钮和分页按钮。
- 点仓库页文件树、发行版按钮和 README 区域。
- 发行版详情页点附带文件即可下载。

### README 全屏

仓库页按 `F`，或点 README 标题栏的「全屏喵~」进入全屏；`j` `k` 滚动，`g` `G` 跳到首尾，`PgUp` `PgDn` 翻页，`F` 或 `Esc` 退出。全屏里仍可点「去 GitHub 看喵~」。

### 语言统计

仓库页按 `L`（或点「语言喵~」）打开语言占比弹窗，按字节数从高到低显示名称、百分比和条形图。

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 上下滚动 |
| `g` `G` | 第一项 / 最后一项 |
| `r` | 重新读取 |
| `Esc` | 关闭 |

### 提交页

| 按键 | 作用 |
| --- | --- |
| `C` | 从仓库页打开提交页 |
| `j` `k` | 切换提交 |
| `Enter` / `o` | 浏览器打开提交详情 |
| `b` | 切换分支并重新读取提交 |
| `r` | 刷新提交 |
| `Esc` | 返回仓库页 |

提交列表包含短 SHA、标题、作者和相对时间；右侧显示完整提交信息，并自动读取本次提交改动的文件、状态和增删行数；文件太多时只显示前几项，按 `o` 去 GitHub 看全部。读取条数由 `commit_limit` 控制（10–100）。

### 用户主页

点击仓库作者（卡片、仓库页标题或右侧小档案）进入。

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 切换仓库 |
| `[` `]` / `PgUp` `PgDn` | 翻页 |
| `Enter` | 打开选中仓库 |
| `o` | 浏览器打开选中仓库 |

仓库页按 `Y`（或点「Fork 喵~」）打开专门的 Fork 小窗口，确认后把别人的仓库 Fork 到自己账号；Fork 成功后仓库会出现在自己的仓库列表里。自己的仓库可以按 `D`（或点「删除喵~」）打开删除确认窗口，确认后仓库会从 GitHub 删除，不能撤销。

## 个人发行版发布 TUI

运行 `gxt release` 打开。界面立即进入，仓库列表在后台用 `gh repo list` 读取；左边显示个人仓库卡片，右边是发布表单、开关和命令预览。

| 按键 | 作用 |
| --- | --- |
| `j` `k` / `↑` `↓` | 仓库列表里移动 |
| `g` `G` | 仓库列表首尾 |
| `r` | 重新读取 gh 仓库列表 |
| `Tab` / `BackTab` | 在仓库列表、标签、标题、目标分支、附件、发行说明、四个开关、发布按钮之间切换 |
| `Enter` | 文本字段下一项；说明框里换行；开关切换；发布按钮上提交 |
| `Space` | 草稿 / 预发布 / 自动生成说明 / 标记最新开关 |
| `Ctrl+S` | 提交发布（会再确认一次） |
| `?` | 打开或关闭帮助 |
| `Esc` | 关闭帮助、取消确认或退出 |
| 鼠标 | 点击仓库卡片、字段、开关、按钮、确认框按钮；悬停高亮；滚轮移动仓库选择 |

右侧字段：标签（必填）、标题、目标分支、附件、发行说明、草稿、预发布、自动生成说明、标记最新；底部实时显示 `gh release create` 命令预览，还有「清空喵~」按钮。

发布调用 `gh release create`：标题留空时用标签；目标分支留空时用仓库默认分支；说明非空时用 `--notes`，否则按「自动生成说明」开关加 `--generate-notes`；草稿、预发布、标记最新分别加对应参数。附件栏填写本地文件路径，多个文件用逗号分隔，支持 `~/`；发布前会检查文件存在，路径会作为 `gh release create` 的附件一起上传。

鼠标 / 手机点击：

- 点击分支、标签、改动、diff、提交、stash 面板会聚焦该面板。

- 滚轮在列表上移动选择，在 diff 上滚动内容。
- 底部快捷键栏支持鼠标悬停高亮，点击会执行对应操作。
