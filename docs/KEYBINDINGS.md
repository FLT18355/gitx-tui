### 首页

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 在置顶仓库之间移动 |
| `Enter` | 打开选中的置顶仓库；没有置顶时跳到搜索 |
| `P` | 置顶 / 取消置顶当前仓库 |
| `E` | 随机打开一个仓库 |
| `T` | 主题工作室 |

### 数据洞察

`9` 或 `I` 打开。页面展示仓库与收藏的语言分布、按 star 数的仓库排行、通知/缓存小账本和 GitHub API 额度条；`r` 刷新，`E` 随机探索，`Esc` 回仓库列表。

### 命令面板

`Ctrl+K` 或 `:` 打开，输入页面名或动作名过滤；`↑` `↓` 挑选，`Enter` 执行，`Esc` 关闭。可跳转全部页面、刷新、切换主题、打开主题工作室或缓存管理。

### 主题工作室

`T` 打开。每行显示主题名、风味和色块预览；`j` `k` 挑选，`Enter` 应用，`Esc` 关闭。也可以直接点击某一行应用。切换后会写入配置（可在设置页 `Ctrl+S` 保存）。

### 设置页

主题卡片、文件树 / README 预览、下载目录、代理、三档缓存时间、提交条数、默认启动页和缓存操作集中在一页。`j` `k` 选行，`h` `l` 调值，`Enter` 操作，`Ctrl+S` 保存。

### 标签页

仓库页按 `v` 进入。`j` `k` 挑标签，`Enter` / `o` 在浏览器打开对应树，`y` 复制标签名，`z` 下载 zip 源码包，`Z` 下载 tar.gz，`u` 复制 SSH 地址，`r` 刷新，`Esc` 返回仓库页。右侧详情里的按钮也能完成同样操作。

### 列表筛选

议题页和提交页按 `/` 聚焦筛选框：议题按标题、作者或标签过滤，提交按提交信息、作者或哈希过滤；`Enter` / `Esc` 离开筛选，`Tab` 直接换页。

### 发行版标签

仓库页发行版列表和发行版详情页的 tag 使用彩底标签；最新版本带星标徽章，预发布带时钟徽章，草稿带警告徽章。列表右侧仍显示文件数和更新时间。

### 鼠标 / 手机点击

- 点击仓库卡片选择，双击打开仓库页。
- 点击卡片或仓库页标题里的仓库作者，进入作者主页；主页里看详细资料和全部公开仓库，点仓库可继续打开。
- 点击排序、语言、主题卡片、按钮和分页按钮。
- 点仓库页文件树、发行版按钮和 README 区域。
- 发行版详情页点附带文件即可下载。

## 个人发行版发布 TUI

运行 `gxt release` 打开。界面立即进入，仓库列表在后台用 `gh repo list` 读取；左边显示个人仓库卡片，右边是发布表单、开关和命令预览。

| 按键 | 作用 |
| --- | --- |
| `j` `k` / `↑` `↓` | 仓库列表里移动 |
| `g` `G` | 仓库列表首尾 |
| `r` | 重新读取 gh 仓库列表 |
| `Tab` / `BackTab` | 在仓库列表、标签、标题、目标分支、附件、发行说明、四个开关、发布按钮之间切换 |
| `Enter` | 文本字段下一项；说明框里换行；开关切换；发布按钮上提交 |
| `Space` | 草稿 / 预发布 / 自动生成说明 / 标记最新开关 |
| `Ctrl+S` | 提交发布（会再确认一次） |
| `?` | 打开或关闭帮助 |
| `Esc` | 关闭帮助、取消确认或退出 |
| 鼠标 | 点击仓库卡片、字段、开关、按钮、确认框按钮；悬停高亮；滚轮移动仓库选择 |

右侧字段：标签（必填）、标题、目标分支、附件、发行说明、草稿、预发布、自动生成说明、标记最新；底部实时显示 `gh release create` 命令预览，还有「清空喵~」按钮。

发布调用 `gh release create`：标题留空时用标签；目标分支留空时用仓库默认分支；说明非空时用 `--notes`，否则按「自动生成说明」开关加 `--generate-notes`；草稿、预发布、标记最新分别加对应参数。附件栏填写本地文件路径，多个文件用逗号分隔，支持 `~/`；发布前会检查文件存在，路径会作为 `gh release create` 的附件一起上传。

| `a` | Stash 面板：应用选中 stash |
| `D` | Stash 面板：删除选中 stash（需确认） |

| `f` | fetch |

鼠标 / 手机点击：

- 点击分支、标签、改动、diff、提交、stash 面板会聚焦该面板。
- 点击列表行会选中对应项并刷新右侧 diff。
- 滚轮在列表上移动选择，在 diff 上滚动内容。
- 底部快捷键栏支持鼠标悬停高亮，点击会执行对应操作。
