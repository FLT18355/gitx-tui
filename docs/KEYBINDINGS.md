# 键位说明

## GitHub 工作台

| 按键 | 作用 |
| --- | --- |
| `1` `2` `3` `4` | 仓库 / 收藏 / 搜索 / 账号 |
| `Tab` | 切换页面；仓库页里切换文件树、发行版、README |
| `j` `k` | 上下移动或滚动 |
| `[` `]` | 上一页 / 下一页 |
| `g` `G` | 第一页 / 最后一页 |
| `PgUp` `PgDn` | 列表翻页或滚动面板 |
| `Enter` | 打开仓库页、执行设置项、打开主页或 Actions run |
| `Esc` | 离开输入、关闭弹窗或返回列表 |
| `/` | 聚焦搜索 |
| `a` | 当前仓库的 Actions 工作流页 |
| `R` / `x` | Actions 页打开「运行工作流」 |
| `c` | 缓存管理 |
| `e` | 编辑自己的仓库 |
| `f` | 收藏或取消收藏 |
| `o` | 用浏览器打开当前仓库 |
| `y` | 复制克隆地址 |
| `r` | 刷新当前页 |
| `Ctrl+S` | 保存设置或仓库编辑 |
| `?` | 操作说明 |
| `q` | 退出 |

### Actions 页

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 切换运行记录 |
| `Enter` / `o` | 浏览器打开 run |
| `R` / `x` | 运行工作流弹窗 |
| `PgUp` `PgDn` | 滚动 jobs/steps |
| `r` | 刷新运行记录 |
| `Esc` | 返回 |

运行工作流弹窗：

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 选择工作流 |
| `Tab` | 在分支和 inputs JSON 输入框间切换 |
| `Enter` | 运行 |
| `r` | 刷新工作流列表 |
| `o` | 浏览器打开工作流 |
| `Esc` | 关闭 |

## 设置 TUI

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 选择设置项 |
| `h` `l` / `Left` `Right` | 调整当前项 |
| `Tab` / `BackTab` | 切换设置项 |
| `Enter` | 执行当前项 |
| `Ctrl+S` | 保存配置 |
| `Esc` | 退出 |

## 本地仓库 TUI

| 按键 | 作用 |
| --- | --- |
| `Tab` / `Right` | 下一个面板 |
| `BackTab` / `Left` | 上一个面板 |
| `j` `k` | 移动选择；Diff 面板里滚动差异 |
| `[` `]` / `PgUp` `PgDn` | 按页移动或滚动 |
| `g` `G` / `Home` `End` | 第一项 / 最后一项 |
| `s` | 暂存选中文件 |
| `u` | 取消暂存选中文件 |
| `S` | 暂存全部 |
| `U` | 取消暂存全部 |
| `d` | 切换暂存 / 未暂存差异 |
| `c` | 提交 |
| `t` | 创建标签 |
| `p` | 推送当前分支 |
| `P` | 推送标签 |
| `f` | fetch |
| `L` | pull（仅 fast-forward） |
| `Enter` | 分支面板切换分支，其他面板刷新差异 |
| `r` | 重新读取仓库 |
| `q` / `Esc` | 退出 |

提交 / 标签输入框：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 提交或创建 |
| `Esc` | 取消 |
| `Ctrl+S` | 提交或创建 |
| `Left` `Right` `Home` `End` | 移动光标 |
| `Backspace` `Delete` | 删除字符 |
