# 键位说明

## GitHub 工作台

| 按键 | 作用 |
| --- | --- |
| `1` `2` `3` `4` `5` | 仓库 / 收藏 / 搜索 / 账号 / 通知 |
| `Tab` | 切换页面；仓库页里切换文件树、发行版、README |
| `j` `k` | 上下移动或滚动 |
| `[` `]` | 上一页 / 下一页 |
| `g` `G` | 第一页 / 最后一页 |
| `PgUp` `PgDn` | 列表翻页或滚动面板 |
| `Enter` | 打开仓库页、执行设置项、打开主页或 Actions run |
| `Esc` | 离开输入、关闭弹窗或返回列表 |
| `/` | 聚焦搜索 |
| `a` | 当前仓库的 Actions 工作流页 |
| `i` | 当前仓库的议题与合并请求页 |
| `R` / `x` | Actions 页打开「运行工作流」 |
| `c` | 缓存管理 |
| `e` | 编辑自己的仓库 |
| `f` | 收藏或取消收藏 |
| `o` | 用浏览器打开当前仓库 |
| `y` | 复制克隆地址 |
| `r` | 刷新当前页 |
| `Ctrl+S` | 保存设置或仓库编辑 |
| `?` | 操作说明 |
| `q` | 退出 |

### 鼠标 / 手机点击

- 点击仓库卡片选择，双击打开仓库页。
- 点击排序、语言、主题卡片、按钮和分页按钮。
- 点仓库页文件树、发行版资产和 README 区域。
- 发行版资产超过 5 个时，点击「还有 N 个资产，点这里全部展开喵~」会展开全部资产；展开后点「收起资产喵~」可以折叠。

### Actions 页

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 切换运行记录 |
| `Enter` / `o` | 浏览器打开 run |
| `R` / `x` | 运行工作流弹窗 |
| `PgUp` `PgDn` | 滚动 jobs/steps |
| `r` | 刷新运行记录 |
| `Esc` | 返回 |

运行工作流弹窗：

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 选择工作流 |
| `Tab` | 在分支和 inputs JSON 输入框间切换 |
| `Enter` | 运行 |
| `r` | 刷新工作流列表 |
| `o` | 浏览器打开工作流 |
| `Esc` | 关闭 |

### 议题与合并请求页

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 切换记录 |
| `Enter` / `o` | 浏览器打开选中记录 |
| `v` | 切换类型：全部 / 议题 / 合并请求 |
| `s` | 切换状态：打开 / 已关闭 / 全部 |
| `g` `G` / `PgUp` `PgDn` | 跳到首尾 / 快速移动 |
| `r` | 刷新 |
| `Esc` | 返回仓库页或列表 |

类型和状态也可以直接点顶部的筛选卡片。

### 通知页

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 切换通知 |
| `Enter` / `o` | 浏览器打开通知对应的页面 |
| `m` | 把选中通知标成已读 |
| `M` | 全部标成已读 |
| `u` | 切换未读 / 全部通知 |
| `r` | 刷新 |
| `Esc` | 回仓库列表 |

## 设置 TUI

| 按键 | 作用 |
| --- | --- |
| `j` `k` | 选择设置项 |
| `h` `l` / `Left` `Right` | 调整当前项 |
| `Tab` / `BackTab` | 切换设置项 |
| `Enter` | 执行当前项 |
| `Ctrl+S` | 保存配置 |
| `Esc` | 退出 |

## 本地仓库 TUI

| 按键 | 作用 |
| --- | --- |
| `Tab` / `Right` | 下一个面板 |
| `BackTab` / `Left` | 上一个面板 |
| `j` `k` | 移动选择；Diff 面板里滚动差异 |
| `[` `]` / `PgUp` `PgDn` | 按页移动或滚动 |
| `g` `G` / `Home` `End` | 第一项 / 最后一项 |
| `s` | 暂存选中文件 |
| `u` | 取消暂存选中文件 |
| `S` | 暂存全部 |
| `U` | 取消暂存全部 |
| `d` | 切换暂存 / 未暂存差异 |
| `c` | 提交 |
| `A` | 修改最后一条提交信息（amend） |
| `t` | 创建标签 |
| `b` | 创建并切换到新分支 |
| `x` | 丢弃选中文件的全部改动（需确认） |
| `z` | stash 当前改动（含未跟踪文件） |
| `Z` | stash pop |
| `p` | 推送当前分支 |
| `P` | 推送标签 |
| `f` | fetch |
| `L` | pull（仅 fast-forward） |
| `Enter` | 分支面板切换分支，其他面板刷新差异 |
| `r` | 重新读取仓库 |
| `q` / `Esc` | 退出 |

鼠标 / 手机点击：

- 点击分支、标签、改动、diff、提交面板会聚焦该面板。
- 点击列表行会选中对应项并刷新右侧 diff。
- 滚轮在列表上移动选择，在 diff 上滚动内容。

提交 / 标签输入框：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 提交或创建 |
| `Esc` | 取消 |
| `Ctrl+S` | 提交或创建 |
| `Left` `Right` `Home` `End` | 移动光标 |
| `Backspace` `Delete` | 删除字符 |
